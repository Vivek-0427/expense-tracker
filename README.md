Expense Tracker Web App

A full-stack Expense Tracker that helps users manage income, expenses, and savings with visual insights.

🚀 Features

💰 Add / Edit / Delete transactions
📊 Visual charts (Income vs Expenses vs Savings)
📂 Category-based tracking
📅 Date-wise expense monitoring
🔍 Insights dashboard
⚡ Responsive UI
🌐 Full-stack (Frontend + Backend)

🛠️ Tech Stack

Frontend
React.js
Tailwind CSS
Backend
Node.js
Express.js
Database
Deployment
Vercel (Frontend)
Render / Railway (Backend)

⚙️ Installation & Setup

1. Clone the repo
git clone https://github.com/your-username/expense-tracker.git
cd expense-tracker

3. Setup Backend
cd server
npm install

Run backend:
npm run dev

3. Setup Frontend
cd client
npm install
npm start
